## Structure rule

The `engineering/` area currently contains only `initiatives/`. Architecture, standards, decisions, and operations folders should be introduced later only when their content becomes independently useful and maintainable.

Every engineering initiative is a directory. A small initiative contains only `README.md`; a larger initiative may also contain focused backend, frontend, or infrastructure documents.
