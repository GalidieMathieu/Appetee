# Appetee

Appetee is a personalized recipe and meal-planning web application that helps users discover meals compatible with their diets and avoided ingredients, save recipes, plan meals, and understand estimated nutrition and cost.

This repository is the central documentation and planning hub for the complete Appetee project.

## Code repositories

- [Appetee Backend](https://github.com/GalidieMathieu/Appetee_v2_BackEnd) — ASP.NET Core API, application logic, MySQL persistence, authentication, and Azure Blob Storage integration.
- [Appetee Frontend](https://github.com/GalidieMathieu/Appetee_v2_frontEnd) — Angular web application, user experience, feature state, forms, and API integration.

## Documentation

This repository contains the canonical product specification, feature documentation, engineering initiatives, roadmap, and reusable documentation templates shared by both code repositories.

Keeping shared documentation here prevents the frontend and backend plans from becoming duplicated or inconsistent.
